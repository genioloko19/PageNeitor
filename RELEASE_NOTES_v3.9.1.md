# Pageneitor v3.9.1 — Windows

Actualización de documentación y experiencia visual.

## Descargar

- `Pageneitor-v3.9.1-win64.zip`
- Descomprime y ejecuta `Pageneitor.exe`.

## Novedades

- **Manual visual completo** con capturas reales de la interfaz.
- Sección de introducción pensada para usuarios nuevos.
- Guía paso a paso de:
  - Pantalla principal.
  - Agrupación por dominio.
  - Detalle de dominio.
  - Asistente de enlaces.
  - Chat flotante.
  - Credenciales multiusuario.
  - Estadísticas y KPIs.
  - Copias de seguridad.
  - Temas.
  - Notificaciones.
- Capturas optimizadas en WebP.
- Panel de Control más ancho para evitar pestañas recortadas.
- Enlaces profundos para abrir vistas concretas.
- Correcciones menores de pluralización.

## Manual con capturas

[Ver el manual visual completo](https://github.com/genioloko19/PageNeitor#-manual-visual)

## Requisitos

- Windows 10/11 64-bit
- Ollama opcional para IA local

## Notas

- Esta versión mantiene la misma base de datos y es compatible con v3.9.0.
- El ejecutable no está firmado; SmartScreen puede mostrar una advertencia.
- Highcharts se usa bajo su licencia gratuita para uso personal/no comercial.
